# Hair Z Salon Website Redesign

## Project Overview
This project is a premium salon website redesign created for the Future Interns UI/UX Internship – Task 1.

The objective of this project was to design a modern, luxurious, and conversion-focused website for a salon business named **Hair Z**, located in **123, Indhranagar, Bengaluru**. The website focuses on user experience, trust-building, appointment booking, and responsive design.

The design was created using **Figma** with a glossy silver and pink aesthetic combined with premium black-and-white salon imagery.

---

## Features

- Luxury and modern salon UI design
- Responsive desktop and mobile layouts
- Appointment booking section
- Service showcase cards
- Customer testimonials
- Premium gallery section
- Conversion-focused CTA buttons
- Elegant typography and clean spacing
- Contact and lead generation form

## UX Decisions

- Used a Black and white color palette to create a premium luxury salon feel.
- Added strong CTA buttons to improve user conversion and appointment booking.
- Used black-and-white premium imagery to maintain a modern and elegant aesthetic.
- Maintained simple navigation and clean spacing for better usability.
- Designed mobile-responsive layouts for better accessibility across devices.
